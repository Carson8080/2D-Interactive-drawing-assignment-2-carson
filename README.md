# 2D-Interactive-drawing-assignment-2-carson

INSTRUCTIONS:

1. Use your mouse to hover your cursor over the red button. You will see it slightly change shade to a lighter red.
2. If you click the left mouse button on any place on the screen that's black, nothing will happen.
3. If you click the left mouse button on the red button while hovering over it, the background wil change to white and the button will change to green.
4. You can still witness a change in shade if you hover over the button.
